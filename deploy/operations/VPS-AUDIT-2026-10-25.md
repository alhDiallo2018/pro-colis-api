## Consequence possible pour les sessions

Une alternance entre deux images/configurations peut expliquer des comportements
intermittents, notamment si les secrets JWT, la base ou les regles de session
different. Cette consequence reste une hypothese : les secrets et les bases
effectivement utilises n'ont pas ete compares. Aucun secret n'a ete affiche.

## Correctif prepare localement

Dans le Caddyfile du depot web, les deux routes `api:8080` sont remplacees par
`sendprocolis-api:8080`, nom unique du conteneur de la stack web de production.
Le code frontend et les autres routes sont inchanges par ce correctif.

La cible proposee est le conteneur de la stack web historique. Avant application,
confirmer que c'est bien l'instance de reference (donnees et configuration).
Le Caddyfile est embarque dans l'image web : une modification du fichier hote
seule ne met pas a jour le proxy deja en cours d'execution. Prevoir validation,
application controlee et restauration de l'ancienne configuration.

L'ignore Docker du depot API exclut desormais explicitement `.env`, en plus de
`.env.*`, pour eviter d'embarquer ce fichier lors d'un futur build. Verifier que
les variables requises sont injectees au runtime avant le prochain deploiement.
